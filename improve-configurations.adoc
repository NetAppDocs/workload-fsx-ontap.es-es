= Implemente configuraciones de sistemas de archivos bien diseñadas
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Aprovecha Workload Factory, basándote en los datos y recomendaciones del análisis de configuración, para aplicar las mejores prácticas en tus sistemas de archivos FSx for ONTAP. Puedes revisar fácilmente el estado well-architected, conocer los problemas de tus configuraciones y tomar medidas para mejorar la arquitectura de cualquier sistema que no esté optimizado para la fiabilidad, seguridad, eficiencia, rendimiento y coste.

También puede descartar el análisis de configuraciones de almacenamiento específicas que no se apliquen a su entorno de almacenamiento para evitar alertas innecesarias y resultados de optimización inexactos.

link:configuration-analysis.html["Conoce el análisis de configuración y el estado de well-architected."]



[[about-this-task]]
== Acerca de esta tarea

Workload Factory analiza a diario las configuraciones de implementación del sistema de archivos de Amazon FSx for NetApp ONTAP. El análisis diario proporciona el estado de well-architected, así como información y recomendaciones con opciones para solucionar automáticamente los problemas de configuración, de modo que tu sistema de archivos cumpla con las mejores prácticas.

La conectividad de enlace permite que Workload Factory busque problemas de rendimiento, protección de datos y configuraciones. link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html["Conectarse a un sistema de archivos FSx para ONTAP mediante un enlace"] para el análisis más completo de los recursos de su sistema de archivos.

Tienes opciones para revisar las recomendaciones sobre problemas de configuración de tus sistemas de archivos y solucionarlos.

Dado que los requisitos de las configuraciones de almacenamiento varían, puedes descartar el análisis de configuraciones específicas que no se aplican a tu entorno de almacenamiento. Esto te ayuda a evitar alertas innecesarias y resultados de optimización inexactos.

.Qué se analiza
Workload Factory analiza el estado de well-architected de las siguientes configuraciones para los sistemas de archivos FSx for ONTAP:

* Fiabilidad: copias de seguridad de volumen, política de snapshots, replicación entre regiones, margen de capacidad de SSD, etiquetas de políticas de replicación y capacidad de objetos de archivo
* Seguridad: Protección contra el ransomware (ARP/AI) y acceso no autorizado a volúmenes iSCSI
* Excelencia operativa: gestión automática de la capacidad, margen de capacidad de archivos de volumen, modo de escritura FlexCache, tamaño de réplica FlexCache, informes de capacidad visibles para el host, tipo de sistema operativo, gestión de espacio en dispositivos de bloques y thin provisioning
* Optimización de costes: clasificación de datos en frío, eficiencias de almacenamiento, caducidad de las copias de seguridad, caducidad de las instantáneas, dispositivos de bloque inactivos, capacidad de SSD sobredimensionada y volúmenes NAS inactivos
* Eficiencia del rendimiento: reequilibrio de volúmenes de FlexGroup y reequilibrio de volúmenes de FlexVol

[[fix-a-configuration-issue]]
== Solucionar un problema de configuración

Puede solucionar problemas de configuración para un sistema de archivos FSx para ONTAP o para volúmenes seleccionados en un sistema de archivos.  Puede seleccionar una o más configuraciones para corregirlas.

Las operaciones de corrección pueden provocar tiempos de inactividad de las instancias o interrupciones del servicio. Revisa cada recomendación detenidamente antes de corregir un problema de configuración.

.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Selecciona el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego selecciona *Well-architected*.
. Selecciona «*Ver y corregir*» para cualquier configuración. Asegúrate de revisar la recomendación con atención.
+
La recomendación explica las prácticas recomendadas y las posibles dificultades de las configuraciones no optimizadas.

. Selecciona los recursos y luego *Corregir*.
+
Algunas operaciones de corrección solo están disponibles para operaciones específicas y no siempre para más de un recurso. Por ejemplo, es posible que puedas corregir la configuración de un único volumen pero no la de varios volúmenes.

. Revisa la información sobre la operación de corrección de la configuración que aparece en el cuadro de diálogo. Algunas operaciones pueden provocar tiempos de inactividad de las instancias o interrupciones del servicio.
. Selecciona *Corregir* si quieres que Workload Factory aplique los cambios recomendados.


.Resultado
Se inicia el proceso de corrección. Selecciona el menú de configuración de la cuenta y luego selecciona *Tracker* para ver el estado de la operación.



[[dismiss-a-configuration-analysis]]
== Descartar un análisis de configuración

Detén un análisis de configuración de forma indefinida para uno o varios recursos. Puedes reanudar el análisis cuando lo necesites.

Haz clic en «Descartar» para detener el análisis de configuración de uno o varios sistemas de archivos o volúmenes FSx para ONTAP. Puedes reiniciar el análisis en cualquier momento.

[role="tabbed-block"]
====
.Descartar un análisis de configuración para configuraciones
--
.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Selecciona el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego selecciona *Well-architected*.
. En Configurations, identifica la configuración que no se aplica a tu entorno.
. Selecciona image:icon-action.png["el icono del menú de acciones"] y luego selecciona *Dismiss*.
. En el cuadro de diálogo Dismiss configuration, selecciona *Dismiss* para detener el análisis de la configuración.


--
.Descartar un análisis de configuración de tus recursos
--
.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Selecciona el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego selecciona *Well-architected*.
. En el panel de control well-architected de FSx para ONTAP, en Configurations, selecciona la configuración que no aplica a tu entorno.
. En la página de configuración, selecciona el/los recurso(s) que deseas excluir del análisis de configuración.
+
** Para un recurso: selecciona image:icon-action.png["el icono del menú de acciones"] y luego selecciona *Descartar*.
** Para varios recursos: selecciona los recursos y luego selecciona *Descartar* junto a Bulk action.


. En el cuadro de diálogo «Dismiss resources», selecciona *Dismiss* para detener el análisis.


--
====
.Resultado
Workload Factory detiene el análisis de configuración para las configuraciones seleccionadas.



[[reactivate-a-dismissed-configuration-analysis]]
== Reactivar un análisis de configuración descartado

Reactiva en cualquier momento un análisis de configuración descartado. Puedes seleccionar una o varias configuraciones o recursos para reactivar.

[role="tabbed-block"]
====
.Reactivar un análisis de configuración para configuraciones
--
.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Selecciona el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego selecciona *Well-architected*.
. Selecciona *Configuraciones descartadas*.
. Identifica la(s) configuración(es) que deseas reactivar y selecciona *Reactivar*.


--
.Reactivar un análisis de configuración de tus recursos
--
.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Selecciona el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego selecciona *Well-architected*.
. En el panel de control well-architected de FSx para ONTAP, en Configurations, selecciona la configuración que no aplica a tu entorno.
. En la página de configuración, selecciona *Configuraciones descartadas*.
. Selecciona los recursos que deseas reactivar.
+
** Para un recurso: selecciona image:icon-action.png["el icono del menú de acciones"] y luego selecciona *Reactivar*.
** Para varios recursos: selecciona los recursos y luego selecciona *Reactivar* junto a Bulk action.




--
====
.Resultado
Workload Factory reactiva el análisis de configuración y ejecuta un nuevo análisis cada día.
