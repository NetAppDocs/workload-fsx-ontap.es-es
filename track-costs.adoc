= Haz seguimiento de los costos de los recursos en NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Utiliza NetApp Workload Factory para hacer un seguimiento de los costes y el uso de tu sistema de archivos FSx for ONTAP, para que puedas gestionar presupuestos y optimizar recursos de forma eficaz. Utilizamos AWS Cost Explorer para proporcionar el coste general con datos que requieren permisos mínimos. El coste por recurso (sistema de archivos o volumen) se basa en los cálculos de Workload Factory, que ofrecen información exclusiva que no está disponible a través de AWS Cost Explorer.



[[about-this-task]]
== Acerca de esta tarea

Workload Factory obtiene datos sobre costes y uso de los recursos de tu sistema de archivos FSx for ONTAP desde AWS Cost Explorer usando los siguientes permisos: `ce:GetCostAndUsage` y  `ce:GetTags`. Se realiza un seguimiento de los siguientes detalles de costes: tipo de uso, SKU de uso, tipo de implementación, uso y coste total.

En el panel de control de costes, hay dos pestañas que muestran el coste total y el coste por recurso.

* El coste total se basa en datos extraídos directamente de la API de AWS Cost Explorer.
* Cost by Resource te muestra estimaciones de costes por sistemas de archivos o volúmenes.
+
En el caso de los recursos únicos, Workload Factory calcula los costes combinando el uso real del nivel de rendimiento, una parte proporcional de los costes del nivel de rendimiento asignados al espacio aprovisionado pero no utilizado, las asignaciones de rendimiento distribuidas por capacidad y el uso del pool de capacidad. Workload Factory multiplica cada componente por su precio por unidad para esa dimensión y suma los resultados para determinar el coste total de cada recurso.



Workload Factory siempre muestra los datos con una tarifa mensual.

Puedes filtrar los datos de costes y uso por cuentas de AWS, credenciales, una o varias regiones e intervalos de tiempo para comprender el consumo de tu sistema de archivos FSx for ONTAP. También puedes filtrar por uno o varios sistemas de archivos y uno o varios volúmenes dentro de un sistema de archivos.

Las claves de etiqueta de asignación de costes de AWS y los valores de las claves de etiqueta añaden un nivel adicional de filtrado para identificar costes específicos. Una _etiqueta_ consta de una clave y un valor. Para filtrar por claves de etiqueta y valores de clave de etiqueta, asigna etiquetas a tus sistemas de archivos FSx for ONTAP. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["Más información sobre las etiquetas de asignación de costes de AWS."^]

Además de los datos de costes en el Cost dashboard, el resumen ejecutivo de costes generado por IA muestra los costes de tu sistema de archivos FSx for ONTAP y los patrones de gasto de tu organización. Puedes generar archivos CSV de los recursos de tu sistema de archivos FSx for ONTAP para compartirlos con tu equipo y las partes interesadas.



[[track-costs]]
== Haz un seguimiento de los costes

Los costes mostrados en la consola Workload Factory en el panel Cost se basan en los datos de AWS Cost Explorer, que se actualizan cada 24 horas.

.Antes de empezar
Comprueba que cumples los siguientes requisitos:

* Debes link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Conceder credenciales con la política de permisos de _visualización, planificación y análisis_"^] en Workload Factory para hacer un seguimiento de los costes de FSx para ONTAP.
* Para filtrar por etiquetas de asignación de AWS, comprueba que tus sistemas de archivos FSx for ONTAP tengan etiquetas asignadas.


.Pasos
. Inicie sesión con uno de los link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiencias de consola"^]botones .
. Seleccione el menú image:workloads-menu-icon.png["El ícono del menú de hamburguesa se utiliza para navegar a cargas de trabajo como almacenamiento, eda, ai, bases de datos, vmware y administración."] y luego seleccione *Almacenamiento*.
. Desde el menú Almacenamiento, seleccione *Costo*.
. Desde el panel de control de Costes, filtra los datos de costes y capacidad de tus recursos FSx para ONTAP proporcionando lo siguiente:
+
.. *Cuentas de AWS*: seleccione las cuentas cuyos datos de costos desea ver.
.. *Credenciales*: seleccione credenciales con permisos de _ver, planificación y análisis_.
.. *Regiones*: seleccione las regiones de AWS para las que desea ver los datos de costos.
.. *Rango de datos de costos*: seleccione el rango de tiempo para ver los datos de costos.
.. *Clave de etiqueta de asignación*: (Opcional) Selecciona una clave de etiqueta de asignación y su valor para generar un informe de costes detallado para todos los sistemas de archivos FSx for ONTAP asociados con la etiqueta AWS.
.. *Valores de etiqueta de asignación*: (Opcional) selecciona el valor de clave de etiqueta de asignación que está asociado con la clave de etiqueta de asignación para generar un informe de costes detallado para todos los sistemas de archivos FSx para ONTAP asociados con la etiqueta AWS.


. Vea los *Detalles de costos* de sus recursos FSx para ONTAP .




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== Genera informes de costes para tus recursos FSx for ONTAP

Genera informes de costes para recursos específicos del sistema de archivos FSx for ONTAP para compartirlos con las partes interesadas.

.Pasos
. En el panel de costes, selecciona *Generar informe*.
. En la pantalla Informe, proporciona la siguiente información:
+
.. *Sistema de archivos*: Selecciona uno o más sistemas de archivos FSx for ONTAP para incluir en el informe.
.. *Volumen*: (Opcional) Selecciona uno o más volúmenes para incluir en el informe.




.Resultado
Workload Factory genera un informe en formato CSV que puedes descargar.
